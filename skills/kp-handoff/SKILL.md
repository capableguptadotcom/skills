# Preserve continuation state

Record the active objective and latest steering, scope, decisions, current branch/worktree and revision when relevant, changed artifacts, checks and their actual results, unresolved problems, and next useful action.

Distinguish completed work from plans and assumptions. Link to authoritative files and outputs instead of duplicating long transcripts. Include a failure that affects the next step; omit abandoned history that does not.

Remove credentials and private content unnecessary for continuation. Save the note to the requested or established location. Preparing a note does not authorize messaging another task or person, archiving, committing, or changing the session state.
