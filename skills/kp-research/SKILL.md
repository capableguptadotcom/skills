# Research a decision

State the question, scope, and what evidence would change the decision. Inspect repository facts and installed versions when relevant. Find the source that owns each consequential claim: official documentation, specification, implementation, release, or experiment.

Open the sources, check dates and versions, and trace secondary commentary to the underlying evidence. Author claims, user reports, and controlled comparisons provide different confidence. A popular repository and a large installation count do not demonstrate task quality.

Compare options against the user's constraints. Separate facts from inferences, unknowns, and recommendations. Cite the page or pinned source that supports each consequential claim. Say when sources disagree or access is missing.

Deliver the findings in the requested format. Save a document only when requested or needed as an agreed task artifact. Delegation is optional and depends on the host and task; it is not a prerequisite for research.
