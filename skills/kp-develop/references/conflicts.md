# Reconcile an active merge or rebase

Confirm the operation, base and unmerged paths. Read both sides and surrounding behavior before choosing the result. Preserve unrelated user work and the user's chosen operation.

Construct a result that preserves both compatible intents; do not choose an entire side simply to remove markers. Surface a conflicting product decision. Regenerate generated files or lockfiles with the project's established tool when appropriate.

Check remaining markers, inspect the reconciled diff and run relevant behavior checks. Stage only resolved task files. Continue or commit when that is within the user's requested operation and repository policy; otherwise leave a precise, reviewable next step. Do not infer authority to abort or discard work from the presence of conflicts.
