# Contributing

Thanks for helping. Every change to a token is crucial for downstream apps — so we review them carefully.

You will recieve a review within two working days. Small fixes can merge with one approval.

## Adding a token

1. Add it to `tokens/base.json` with a description.
2. Run `npm run build:tokens` and commit the generated files.
3. Note the change in `CHANGELOG.md` under Unreleased.
