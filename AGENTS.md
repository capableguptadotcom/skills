# Maintaining this collection

Keep `skills/kp-*/SKILL.md` portable and narrowly triggered. Preserve user intent and existing authorization. Do not install upstream collections, rewrite global agent settings, or execute upstream helpers merely to inventory them.

Canonical inputs are `sources.json`, `reviews.json`, and owned `skills/`. The observed lock and catalog are generated by `scripts/upstreams.py`. A fetched source is not a reviewed source. Keep old review anchors until the changed content and dependencies have actually been assessed.

For a skill change, verify the observable behavior and its neighboring negative case. Report a smoke test as a smoke test. Do not claim measured improvement without a comparable baseline. Raw conversations and private-source material belong under ignored local storage.

Before publishing repository changes, run:

```sh
python scripts/validate.py
python -m unittest discover -s tests -v
git diff --check
```

Stage explicit task files. Use a draft PR for upstream candidate updates; do not merge automatically or overwrite owned wording from upstream.
